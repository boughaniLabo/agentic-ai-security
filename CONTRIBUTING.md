# Contributing

This repository is part of **Abdelghani Demmouche's** cybersecurity portfolio. While primary content is authored personally to reflect real hands-on lab work, constructive feedback, bug reports on detection rules/scripts, and suggestions are welcome.

## Guidelines

1. **No Confidential or Proprietary Data:** Never submit logs, rules, or configs from real production environments.
2. **No Live Exploit Payloads:** Keep all offensive or testing material strictly educational, lab-scoped, and compliant with `SECURITY.md`.
3. **Quality Checks:** Ensure all Markdown files pass `markdownlint` and no secrets trigger `gitleaks`.
